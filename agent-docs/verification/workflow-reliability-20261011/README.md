## Independent pilots

available tools and permissions/budgets. Expected outcomes are withheld. Frozen
original/revised dependency skills use fresh contexts and matching fixtures;
implementation pilots pin their relevant skill/runner resources. Assessors check

counts, latency, tokens and accepted-without-correction outcomes therefore stay
unmeasured. Reports and verified artifacts can support narrower correctness
findings, but not a broad efficiency or statistical superiority claim.
